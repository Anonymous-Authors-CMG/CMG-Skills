## HOW TO JUDGE
- "fixes": the change resolves the problem or request the issue describes.
- "partial": the change clearly works on that issue but does not finish it.
- "unrelated": sharing a file, module or vocabulary is NOT enough. If you cannot
  point to a concrete connection between the code change and the issue, choose this.

confidence: "high" only when the connection is specific and checkable (same
function, same error message, same behaviour). Otherwise "medium" or "low".

## OUTPUT FORMAT — VERY STRICT
Return ONLY one JSON object, no prose, no code fences:
{"verdict": "fixes" | "partial" | "unrelated", "confidence": "high" | "medium" | "low", "reason": "one or two sentences citing the concrete evidence"}
