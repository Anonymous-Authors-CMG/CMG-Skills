## Make it yours

| Setting | Try |
|---|---|
| `issueCommit.message.language` | `en` or `zh-CN` (default follows VS Code) |
| `issueCommit.message.format` | `plain` if your project doesn't use Conventional Commits |
| `issueCommit.message.trailer` | `fixes` to close issues on merge, `none` for no reference |
| `issueCommit.message.instructions` | House rules, e.g. "scope must be one of api, ui, docs" |
| `issueCommit.workflow.scmButton` | `quick`: no panel, pick the issue in a list, done |

Put message settings in **workspace** settings to share them with your team.
